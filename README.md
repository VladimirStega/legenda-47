# Легенда №47

Интерактивный макет сайта школьного спортивного клуба школы №47 города Липецка.
Исходники актуального макета находятся в `dist/playground.html` и подключённых CSS/JS-файлах.
Награды клуба — в `dist/assets/awards`, подписи — в `dist/awards.js`.

## GitHub Pages

Сайт публикуется автоматически при обновлении ветки `main` через GitHub Actions.
В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**.
На главной странице открывается текущий макет с доской; исходная концепция сохранена по ссылке «Первый вариант».

Подготовить файлы для публикации локально:

```sh
node scripts/build-pages.mjs
```

Результат находится в `_site/`. Сборка не требует установки npm-пакетов.

Фотографии с подписью «Фото-пример» демонстрационные. Их предстоит заменить материалами школы.
