# Легенда №47

Сайт школьного спортивного клуба школы №47 города Липецка.
Главная страница собирается из `dist/playground.html` и подключённых CSS/JS-файлов.

- Награды: `dist/assets/awards`, подписи: `dist/awards.js`.
- Фотографии школьных Олимпийских игр: `dist/assets/gallery/olympics`.
- Содержание разделов и ссылка на видео: `dist/customer.js`.

## GitHub Pages

Сайт публикуется автоматически при обновлении ветки `main` через GitHub Actions.
В настройках репозитория **Settings → Pages → Source** выбран **GitHub Actions**.
На сайте доступна одна актуальная версия с доской.

Подготовка файлов для публикации:

```sh
node scripts/build-pages.mjs
```

Результат находится в `_site/`. Сборка не требует установки npm-пакетов.
